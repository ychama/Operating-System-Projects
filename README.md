# OS Projects

This repository contains several projects related to operating systems, memory management, and concurrency. Below is a short overview of each project and a link to its dedicated README for more details.

1. **Round-Robin CPU Scheduling Simulator**  
   A simulator that performs Round-Robin (RR) CPU scheduling on processes, computing start and finish times, and generating an execution sequence.  
   **[View Project &rarr;](./cpu_scheduler/README.md)**

2. **Best-Fit Dynamic Partition Memory Allocation**  
   A memory allocation simulator that manages partitions in a best-fit fashion, merges adjacent free blocks, and reports memory usage stats.  
   **[View Project &rarr;](./memory_simulator/README.md)**

3. **FAT Table Simulation**  
   Analyzes a File Allocation Table (FAT) to determine the largest possible file (longest terminated chain) and count unused blocks.  
   **[View Project &rarr;](./fat_memory_detector/README.md)**

4. **Multi-Threaded Factor Sum**  
   A program that computes the smallest non-trivial factor for large integers in parallel, using pthreads, barriers, and thread cancellation techniques for speedup.  
   **[View Project &rarr;](./multi-thread-sum-factor/README.md)**
